# Simulation Overview

## Purpose
Simulation was used to validate firmware execution, control flow,
and safety logic before hardware availability.

## Scope
* Firmware behavior verification
* Fault detection and latching logic
* Motor enable and shutdown behavior
* UART-based system observation

## Method
* Proteus schematic instantiated per design
* Sensor inputs emulated conceptually
* System behavior observed via UART and GPIO indicators

## Outcome
Simulation successfully validated system-level logic and safety behavior,
with electrical validation deferred to hardware testing.
